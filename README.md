# STEP NAVI

求職者向けキャリア学習支援サイト。ETOILEキャリアアドバイザー事業の一環として、面談後の求職者にスキルアップ機会を提供します。

## コンテンツ

- **ビジネスマナー** — 面接・メール・職場の基本
- **資格取得ガイド** — 生成AIパスポート・MOS
- **AI活用入門** — ChatGPTの基本と仕事への活用
- **職種図鑑** — 事務・営業・施工管理など12職種
- **プロンプト集** — コピペで使えるAIプロンプト
- **AI時代のキャリア** — これからの働き方・現業の価値

## 技術

- 静的HTML（ビルドツールなし）
- Tailwind CSS（CDN）
- Inter + Noto Sans JP（Google Fonts）
- Lucide Icons
