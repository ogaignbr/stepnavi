Excel基本

事務職を目指すなら避けて通れないExcel。表の作成・データ整理・簡単な関数まで、まずはここをマスター。

この記事の使い方

この記事で分かること

転職活動で使える要点を短く確認できます。

読む目安

3〜5分で読めるように、重要ポイントを先に整理しています。

次にやること

読み終えたら、書類作成・面接準備・LINE相談につなげましょう。

1. セル入力の基本

Excelは縦×横のマス目（セル）に文字や数字を入力するソフトです。クリックしたセルが青く囲まれ、入力できます。確定は Enter キー。

移動のコツ: Enter で下、Tab で右、矢印キーで上下左右にセル移動できます。

2. 行と列の追加

  1. 追加したい行/列の番号（左端の1,2,3.. or 上のA,B,C..）を右クリック
  2. 「挿入」を選択
  3. その位置に空の行/列が追加される

3. 表の作成

見出し行を1行目に入れて、その下にデータを並べるのが基本。完成したら以下の方法で「表」スタイルに変換できます。

  1. データ範囲を選択（左上から右下までドラッグ）
  2. 「ホーム」タブ →「テーブルとして書式設定」
  3. 好きなデザインを選ぶ → OK

4. フィルター

大量データから条件に合うものだけ表示する機能。

  1. データの先頭行（見出し）をクリック
  2. 「データ」タブ →「フィルター」をクリック
  3. 各列の見出しに ▼ が表示されるので、絞り込みたい値を選ぶ

5. 並び替え

データを「金額が大きい順」「五十音順」などに並べ替える機能。

  1. 並び替えたい列のセルを1つ選択
  2. 「データ」タブ →「並べ替え」
  3. 「最優先されるキー」と「順序（昇順/降順）」を選んで OK

6. よく使う関数 4選

関数は「セルに =関数名(範囲) と書く」だけで自動計算できる便利機能。

SUM合計を出す

例：=SUM(A1:A10) → A1からA10までの合計

AVERAGE平均を出す

例：=AVERAGE(B1:B10) → B1からB10までの平均

COUNT数値の個数を数える

例：=COUNT(C1:C10) → C列内の数値が入っているセル数

IF条件分岐

例：=IF(D1>=60,"合格","不合格") → D1が60以上なら「合格」、未満なら「不合格」

覚え方: まずは SUM だけでOK。数字の合計を出せると「Excel使える人」っぽくなります。

7. 印刷設定

Excelの印刷は「思った通りに出ない」あるある。事前に印刷プレビューを確認しましょう。

  1. Ctrl + P で印刷プレビューを表示
  2. 右側の「印刷設定」で「シートを1ページに印刷」を選ぶと、横にはみ出さない
  3. 用紙の向き（縦・横）も確認
  4. OKなら「印刷」ボタン

まとめ

Excelは「セル入力 → 表作成 → 関数で計算 → 印刷」の流れ。まずは家計簿でも作りながら、SUM関数とフィルターから慣れていきましょう。
