PowerPoint基本

使う頻度はそこまで多くないですが、簡単な資料作成・発表用スライドが作れると役立ちます。

1. スライドを作る

PowerPointを開くと最初のスライド（タイトルスライド）が表示されます。新しいスライドを追加するには：

  1. 「ホーム」タブをクリック
  2. 「新しいスライド」をクリック
  3. スライドのレイアウト（タイトルと内容など）を選ぶ

2. テキスト入力

スライド上の「タイトルを入力」「テキストを入力」と書かれた箱（プレースホルダー）をクリックして文字を入力します。

レイアウトのコツ: 1スライドに情報を詰め込みすぎないこと。「1スライド1メッセージ」が見やすい資料の鉄則です。

3. 画像の挿入

  1. 「挿入」タブをクリック
  2. 「画像」→「このデバイス」を選択
  3. 挿入したい画像を選んで「挿入」
  4. 角をドラッグしてサイズを調整、中心をドラッグして移動

4. 図形を作る

矢印・四角・丸などの図形でフロー図や強調枠が作れます。

  1. 「挿入」タブ →「図形」
  2. 使いたい図形（矢印・四角など）を選ぶ
  3. スライド上でドラッグして描画
  4. 図形をクリック→「図形の塗りつぶし」で色変更

5. 簡単な資料作成の流れ

シンプルな提案資料を作る流れ：

  1. 1枚目：表紙（タイトル＋名前）
  2. 2枚目：目的・概要
  3. 3〜5枚目：本題（1スライド1メッセージ）
  4. 最後：まとめ＋連絡先

デザインのコツ:「デザイン」タブから既成テーマを選ぶと、全体の見た目が一気に整います。色は3色以内に絞ると統一感が出ます。

まとめ

PowerPointは「スライドにテキスト・画像・図形を配置する」だけのシンプルなツール。凝った装飾より、「1スライド1メッセージ」を意識すれば伝わる資料が作れます。
