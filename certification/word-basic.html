Word基本

文書作成の定番ソフトWord。報告書・案内文・履歴書まで、これだけ覚えれば一通り作れます。

1. 文字入力の基本

新規Word文書を開いたら、カーソルが点滅している場所に文字を入力します。改行は Enter キー。

変換のコツ: ひらがなで入力→スペースキーで漢字変換→Enterで確定。これだけです。

2. フォント変更

  1. 変更したい文字をマウスでドラッグして選択
  2. 「ホーム」タブの左上にあるフォント名（例：游明朝）をクリック
  3. 使いたいフォントを選ぶ（ビジネス文書なら游ゴシック・メイリオが定番）

3. 文字サイズ変更

文字を選択した状態で、フォント名の右にある数字（11 など）をクリックして変更。タイトルは14〜18pt、本文は10〜11ptが標準。

4. 箇条書き作成

  1. 箇条書きにしたい行にカーソルを置く
  2. 「ホーム」タブの「箇条書き」アイコン（・が並んだマーク）をクリック
  3. 各項目を Enter で改行しながら入力

5. 表の作成

  1. 「挿入」タブをクリック
  2. 「表」アイコンをクリック
  3. マス目をドラッグして「3列×4行」のように指定
  4. 表が挿入されたら、各セルに文字を入力

6. 画像の挿入

  1. 「挿入」タブをクリック
  2. 「画像」→「このデバイス」を選択
  3. 挿入したい画像ファイルを選んで「挿入」
  4. 画像をクリックして角をドラッグ → サイズ調整

レイアウトのコツ: 画像を右クリック→「文字列の折り返し」→「四角」を選ぶと、文字が画像の周りを自然に流れます。

7. PDFとして保存

完成した文書をPDFで提出する時に使います。

  1. 「ファイル」タブをクリック
  2. 「名前を付けて保存」を選択
  3. ファイルの種類で「PDF」を選択
  4. 保存場所を決めて「保存」

まとめ

Wordは「文字を打つ→飾る→保存」がすべての基本。最初は1ページの案内文を作る練習から始めましょう。慣れたら表や画像を組み合わせてレイアウトに挑戦。
