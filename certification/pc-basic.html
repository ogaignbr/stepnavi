PC基礎スキル

「パソコンが少し苦手…」という方も大丈夫。これだけ覚えれば、毎日の作業がぐっとラクになる基本操作をまとめました。

1. ショートカットキー一覧

マウスでメニューを開かなくても、キーボードで一発操作できる便利な組み合わせです。最初は「コピペ」と「保存」だけでもOK。

Ctrl + Cコピー
Ctrl + V貼り付け
Ctrl + X切り取り
Ctrl + Z元に戻す（取り消し）
Ctrl + Yやり直し
Ctrl + S上書き保存
Ctrl + A全選択
Ctrl + F検索
Ctrl + P印刷
Alt + Tabアプリ切り替え
Win + Dデスクトップを表示

覚え方のコツ: まず「Ctrl+C / V / Z / S」の4つだけ覚えれば、9割の場面で困らなくなります。

2. フォルダ作成

書類を整理する「箱」を作る操作です。デスクトップやドキュメント内に作れます。

  1. フォルダを作りたい場所（デスクトップなど）で右クリック
  2. 「新規作成」→「フォルダー」を選択
  3. フォルダ名を入力して Enter キー

3. ファイル保存

作業内容を残しておくには、必ず「保存」が必要です。

  1. キーボードで Ctrl + S を押す
  2. 初回は「名前を付けて保存」が開くので、保存先と名前を決める
  3. 2回目以降は同じ場所に上書きされる

注意: 大事な作業は こまめに Ctrl+S。フリーズしてもダメージが最小限になります。

4. ファイル名の変更

  1. 名前を変えたいファイルをクリックして選択
  2. F2 キー を押す（または右クリック→「名前の変更」）
  3. 新しい名前を入力して Enter

5. ZIPファイルの圧縮と解凍

圧縮（複数ファイルを1つにまとめる）

  1. まとめたいファイルを複数選択（Ctrl押しながらクリック）
  2. 右クリック → 「ZIPファイルに圧縮する」
  3. 同じ場所に .zip ファイルができる

解凍（ZIPを開く）

  1. ZIPファイルを右クリック
  2. 「すべて展開」を選択
  3. 展開先を確認して「展開」をクリック

6. スクリーンショット取得

画面の様子を画像として保存する方法。エラー画面を共有したい時などに便利。

Win + Shift + S範囲を選んで撮る（おすすめ）
PrintScreen画面全体をクリップボードへ
Win + PrtScn画面全体を画像ファイルで保存

7. PDFの基本操作

PDFを開く・保存する

PDFファイルはダブルクリックすれば標準のブラウザ（Edge/Chrome等）で開けます。保存はブラウザ上のダウンロードボタン、または Ctrl+S。

PDFを印刷する

PDFを開いた状態で Ctrl + P。プリンターを選んで印刷ボタン。

PDFを結合・分割する

無料の Web サービス（例：iLovePDF、SmallPDF）で簡単にできます。PDFをアップロード→操作→ダウンロードの3ステップ。

セキュリティ: 機密情報を含むPDFは、信頼できるサービスのみで操作しましょう。社内データは外部にアップしないのが基本です。

まとめ

PC操作は「最初の数個」を覚えれば、あとは応用です。Ctrl+C/V/Z/S の4つから始めて、慣れたらフォルダ・ZIP・スクショへと広げていきましょう。
